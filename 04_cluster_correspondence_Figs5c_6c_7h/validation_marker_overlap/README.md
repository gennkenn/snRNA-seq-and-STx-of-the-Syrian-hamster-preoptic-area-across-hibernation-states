# Independent check of the label-transfer correspondence by marker-gene overlap

`marker_overlap_check.R` tests whether the cluster pairs identified by label transfer (Figs. 5c, 6c) also share marker genes when markers are derived in each dataset **independently**, without any use of the label-transfer result.

Procedure (one run per class, `CLASS=Ex` / `CLASS=Inh`):

1. Both objects are restricted to their shared genes (13,312 excitatory / 13,978 inhibitory) and log-normalised from raw counts.
2. `FindAllMarkers` (one-vs-rest, Wilcoxon, `only.pos = TRUE`, `min.pct = 0.1`, `logfc.threshold = 0.25`, Bonferroni-adjusted p < 0.05) is run separately in the cross-species atlas (subtypes e/i) and in the cross-condition dataset (clusters 0–n); each set is capped at the top 100 markers by `avg_log2FC`.
3. For every (cross-condition cluster × atlas subtype) pair: number of shared markers, Jaccard index and a hypergeometric p value over the shared-gene universe.
4. For each cross-condition cluster, the atlas subtype with the highest Jaccard is compared with the label-transfer best match (`source_data/correspondence_table_<CLASS>.csv`).

## Result

| | Excitatory (51 clusters) | Inhibitory (53 clusters) |
|---|---|---|
| label-transfer best match = marker-overlap best match | 38 / 51 | 42 / 53 |
| label-transfer best match within top 3 by marker overlap | 44 / 51 | 51 / 53 |
| agreement among reciprocal-best pairs | 28 / 31 | 28 / 30 |
| agreement among non-reciprocal clusters | 10 / 20 | 14 / 23 |
| median Jaccard of the label-transfer best match | 0.161 | 0.170 |
| median Jaccard over all pairs (background) | 0.020 | 0.020 |
| hypergeometric p < 0.001 for the label-transfer best match | 48 / 51 | 52 / 53 |

Files:

| File | Content |
|---|---|
| `marker_overlap_summary_<CLASS>.csv` | one row per cross-condition cluster: label-transfer best match, marker-overlap best and second-best, Jaccard, shared-marker count, hypergeometric p, rank of the label-transfer match |
| `marker_overlap_selected_<CLASS>.csv` | five reciprocal pairs spanning the range of `frac_best`, with the list of shared marker genes |
| `marker_overlap_jaccard_<CLASS>.csv`, `marker_overlap_count_<CLASS>.csv` | full cluster × subtype matrices (Jaccard; shared-marker counts) |

The full marker tables (`markers_ref_<CLASS>.csv`, `markers_qry_<CLASS>.csv`, FindAllMarkers output before capping) are not stored here because of size; they are regenerated by the script.
